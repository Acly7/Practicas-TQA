# Practicas - TQA

## Descripcion
Repositorio para almacenar y organizar las practicas, ejercicios y actividades realizadas durante la materia.

## Objetivo
Mantener un registro ordenado de los trabajos desarrollados, utilizando Git y GitHub para el control de versiones.

## Contenido
- Practicas de laboratorio
- Ejercicios de clase
- Evidencias
- Documentacion

## Organizacion
- practicas: trabajos de laboratorio.
- ejercicios: actividades realizadas en clase.
- evidencias: capturas y resultados.
